## Fairness and limitations

The Git baseline is **not merely an unsigned comment containing a hash**. It is an intentionally strong baseline: keys are pre-pinned, Git annotated tags are signed per role, a signed close enumerates commitments, and dispositions are required. Giving it the same integrity obligations prevents trivial benchmark wins from missing functionality in the control. This increases the baseline's complexity and means the trial does **not** yet quantify whether a plain public commit/reveal comment is sufficient.

The test uses local Git refs, not a genuinely independently witnessed public GitHub publication. Neither platform has real external chronology here. A malicious steward who deletes the entire local record and all independent witness copies, collusion, authenticity of identity, packet-release exposure, mixed client versions, and external trust pin governance are untested. Review Record's signed receipts could matter when an external reviewer retains one; that question is specifically **not resolved** by these fixtures.

## Disposition

The proposed stop criterion was triggered on this first, intentionally limited attack set. Do not justify additional Review Record feature-building by claiming superior detection of these five attacks.

**Next falsification before choosing architecture:** devise two equally evidenced cross-party suppression cases (the author/steward deletes the working record but the reviewer retains a signed acknowledgment; alternatively the baseline retains a publicly witnessed signed tag). Require both designs to use the same independent witnesses. Independently check the resulting reports and quantify operating complexity. If Review Record still provides no material incremental integrity finding with equivalent evidence, investigate replacing its bespoke mechanisms with signed Git plus existing transparency/timestamp components.

Do not merge this experiment into PR #2, start Round 1, or present these results as evidence of research correctness or reviewer independence.
