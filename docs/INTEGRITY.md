# Integrity contract for the implemented slice

Task: evaluate whether a supplied candidate is established by supplied synthetic evidence. This is not a naive implication task; that task needs a separate packet without the supplied candidate.

Before packet delivery: reviewer explicitly declares conflict, prior results/peer exposure and AI judgment assistance. A different steward applies the fixed policy. Conflicting/exposed/AI-assisted evaluative judgments cannot enter the protected route in this prototype. This is a policy, not a statement that other contributions lack value.

Before opening: author freezes question, evidence/candidates, withheld-material commitment, deadline, assignment roster including account IDs, author/steward roles, and disclosure/assistance/operator-trust terms. No material edits are supported after freeze. New 0.2 corrections create linked draft versions; frozen versions are not edited. External hash publication is recorded before opening new 0.2 rounds; it is an author attestation, not independently verified chronology.

Before closure: reviewers see only their own packet/assessment. Author and steward routes expose progress, declarations and eligibility, but not initial assessment bodies. The operator still controls storage. A locked initial submission never becomes an editable draft; amendments remain distinct.

Closure: all frozen assignments submitted, or the frozen deadline elapsed. An ineligible/missing reviewer is not silently removed to permit early closure. This prototype deliberately favors a simple fixed rule. It may be inconvenient; more flexible policies must be frozen, tested and disclosed before adding them.

After closure: eligible reviewers can request withheld material only if no other open assignment in the study remains for them. The tool records delivery, not proven reading. Peer assessments stay private in v0.1. New 0.2 rounds allow non-calibration peer work only after closure and only when no related frozen/open assignment remains. Calibration reports stay steward-only. Later result/external exposure persists across study versions in eligibility checks. No record can establish the absence of exposure outside the tool.

A private export includes original submissions, later amendments, eligibility/exposure records, missing assignments and application events. Feedback text/records are excluded and use a feedback-only export. Author exports redact calibration responses; complete steward exports remain private. It is not a journal certificate or a safe public export. Reviewer receipts allow later consistency checks; an external trusted witness is needed for independent chronology claims.

Conflict declarations, eligibility decisions and cryptographic receipts answer different questions. None makes the underlying evidence or scientific conclusion correct. A self-hosted tool cannot guarantee honest selection of reviewers or honest reporting by its owner.
