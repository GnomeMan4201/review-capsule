[demonstrated here] Repair uses the unchanged fixtures.refresh_manifest helper. In addition to the manifest, it regenerates record.ots and changes the two record-anchor descriptor targets. A targeted record descriptor that was deleted or corrupted is temporarily supplied from the base solely so the helper can run; its exact mutation is restored afterwards. This prerequisite adaptation is flagged per trial. No other signatures, logs or object bindings are repaired. It is not a self-consistent semantic rebuild.

[demonstrated here] Mocking stays explicit. The original simulated_anchors byte gate is reused with base expectations for all proofs except the helper-regenerated record.ots. That expected proof is updated to the exact bytes generated by the helper. Otherwise every non-anchor mutation changing the record hash would be masked by the mock rejecting the repaired record proof. Other proof corruption is not blessed by resetting mock expectations from the mutated bundle. Real proof parsing and authority qualification are not exercised.
