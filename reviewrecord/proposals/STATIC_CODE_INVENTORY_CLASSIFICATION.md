# Static code inventory classification — incomplete, not a requirement map

[demonstrated here] This is the 68-entry static literal inventory retained in PR #7's `meta-probe.json` at `12de4dce40ab7cd0ddc73fe5d60c7364bbfb525f`, whose verifier is pinned to `d54432f3`. It is incomplete and is not a requirement map. No mandatory-check registry or design is selected; draft #12 remains draft and unselected.

[demonstrated here] The probe says: “Static literal inventory, not a reachability proof or mutation coverage claim.” Its result says `exhaustive_per_code_coverage`: “unknown; no evidence-to-code reachability/requirement map exists; diagnostic and absent-set cases cannot be generated by mutating an emitted row alone”. In particular, the extractor does not collect `FORBIDDEN_CLAIM_PRESENT`, which report.py emits through a directly appended dictionary. Newer revision diagnostics are outside this pinned list.

[assumed] Classification definitions: **fixture-reachable** means an emitted row is witnessed in the reference/mock baseline or retained file trials, not that all its branches have been exercised. **absence-only** means this code reports a missing expected object/input/coverage set under its applicability condition (even when a malformed object is treated as absent); file deletion can reach several of these. It does not mean byte mutation is universally unable to reach it. **unknown** means no witness was established in the inspected baseline/file-trial artifacts, not that the code is unreachable. Absence-only takes precedence over a witnessed row.

[assumed] The obligation/diagnostic column distinguishes predicate results, failure-only diagnostics and attributed notices. It does not decide that any row is mandatory. Conditions, multiplicities, evidence descriptions and proposed discriminating fixtures are source readings, not newly executed per-code tests. The final column supplies a witnessed trigger when available, plus a proposed isolating fixture; proposed fixtures are **[assumed]**, unrun, and can still require re-signing/rebinding to avoid another failure masking the predicate. A witnessed row is not an isolated predicate proof. Runtime, backend, ZIP and caller-input branches are not comprehensively exercised here.
