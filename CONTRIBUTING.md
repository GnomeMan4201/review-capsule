# Contributing

Start with synthetic fixtures and the threat model. Useful early contributions: authorization review, endpoint leakage tests, PostgreSQL race tests, receipt/export verification and mobile accessibility checks.

Do not upload real protected study packets, reviewer identities, judgments, credentials or private exports to public issues, fixtures or pull requests. Do not silently weaken a frozen rule to make the demo convenient. Explain the effect of a proposed change on disclosure, reviewer eligibility and existing round compatibility.

AI assistance in code should be disclosed in the contribution. Generated code and additional test counts do not constitute independent security or scientific review. Protected evaluative judgments follow the declared round policy; this repository is not a mechanism for laundering AI judgments as human labels.
